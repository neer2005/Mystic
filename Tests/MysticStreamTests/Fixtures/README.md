# Integration fixtures

Original synthetic FFmpeg `testsrc2` output, dedicated to CC0-1.0:
https://creativecommons.org/publicdomain/zero/1.0/

Regenerated by `scripts/generate-video-fixtures.py` alongside the profile probes.
`h264-key.bin` and `h264-p.bin` are consecutive 64×64 access units from the same
GOP. `h264-resize.bin` is a 128×64 keyframe with a different SPS.

`audio-stereo.json` and `audio-surround51.json` contain 5 ms Opus packets from
original synthetic, per-channel sine waves. The channel map in each JSON is
permuted from Ogg Vorbis order to Windows speaker-mask order, matching Nightjar's
consumer contract. Regenerate with `scripts/generate-audio-fixtures.py`; the data
is also CC0-1.0. No microphone recordings or third-party audio are included.
